# TechNexus — Product Showcase

A static, responsive product showcase website for Vercel.

## Features
- Responsive desktop/tablet/mobile layout
- 5 uploaded product images
- Product prices in BDT
- Search
- Category filters
- Product detail modal
- No cart, checkout, payment or selling flow
- Pure HTML/CSS/JavaScript — no build step required

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
Upload this folder/repository to Vercel. Since this is a static site, no framework or build command is required.
